REM Recombinator

A procedure that proposes a few collisions between weakly related notes, then rejects almost all of them by a rule you can recompute.

Your chats are not on this page. The repository, the nightly artifact, and this site contain seven invented sentences. The install command writes a database under your home directory and does not upload it.

Claim Procedure Geometry Decision rule One command

01What is being claimed

The name is a computational sketch of REM sleep, not a claim about brains. During REM, weakly linked traces are reactivated together and most of those collisions are noise. This program does the analogous thing on purpose, on text you already have, and it writes down every choice.

Public

Method and sample

Selection rules, thresholds, the critic formula, and a seven-sentence corpus anyone can rerun. The hash embedder is a reproducibility stand-in. It is not evidence about meaning.

Private

Your store

SQLite at ~/.local/share/rem-recombinator/state/fragments.db. The file is created on first use. It is gitignored. Nothing in the install reads a chat transcript.

Optional

A remote model

The installed server uses an offline template. Fragment text leaves the machine only if you later point REM_EMBEDDER or REM_LLM at an API and add keys.

02Procedure

Cosine similarity, with a zero vector defined as similarity 0:

cos(u, v) = (u · v) / (||u|| ||v||)

Semantic bridge

Different clusters, near band

Greedy leader clustering at link 0.55. A pair must sit in different clusters and in cosine [0.05, 0.35]. The score is the novelty of the normalized midpoint.

Analogical transfer

Different domains

Domains must differ, and neither may be unspecified. Inside cosine [0.15, 0.55] the score is the cosine itself: a shared direction across tags.

Dialectic synthesis

A listed opposition

A documented cue list, not an entailment check. Tension times closeness to cosine 0.45, and the pair must lie in [0.20, 0.75].

m = normalize(normalize(u) + normalize(v))
S = 1 − max cos(m, v_k)     over fragments other than the pair

A hypothesis is dropped when its nearest neighbour is above 0.88 or below 0.05.
The model does not set the accept bit.

04The accept rule

Four axes, each in [0, 1]. The composite is fixed. A report is accepted only when the composite clears 0.60 and every axis clears 0.30. The template model used by the public demo scores every axis at 0.50, so it accepts nothing. That is the gate working.

C = 0.30 N + 0.30 L + 0.20 F + 0.20 U
accept  ⟺  C ≥ 0.60  and  min(N, L, F, U) ≥ 0.30

05One command, any MCP chat

The chat program does not matter, as long as it can launch a local stdio server. Cursor and Claude Desktop are registered when their config directories exist. Every other host can use the same command, which the installer also writes to mcp-snippet.json.

curl -fsSL https://raw.githubusercontent.com/bernhardbrugger/rem-recombinator/main/install.sh | bash
  1. Run the command. It clones the repository under ~/.local/share/rem-recombinator, creates a virtualenv, and links rem-recombinator onto ~/.local/bin.
  2. Restart the chat client. The server is named rem-recombinator. It does not open your transcripts.
  3. When you want a corpus, import a file that already lives on the machine. A Claude memories export, a neutral JSON list, or a folder of notes all work. A hidden file in that folder is skipped.
rem-recombinator import ./fragments.json --embedder hashing
rem-recombinator import ./notes/ --embedder hashing
rem-recombinator demo

fragments.json is {"fragments": [{"text": "...", "domain": "physics"}]}. In a directory, the folder name is the domain. demo reruns the fictional sample in a temporary database and does not open your store. The source is github.com/bernhardbrugger/rem-recombinator.

Thresholds on this page are the repository defaults. The plane is regenerated by scripts/build_demo_geometry.py and checked in tests against that function. A nightly Action reruns the same fictional cycle; it does not grow a personal memory.
