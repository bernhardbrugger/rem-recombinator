REM Recombinator

A note on a rejection-heavy recombination procedure

Public demonstration. The corpus is fictional.

Abstract

The procedure selects pairs of stored fragments by an explicit geometric rule, asks for one hypothesis, and discards that hypothesis unless it clears a novelty window and a four-axis critic. The name is a computational sketch of REM sleep, not a claim about brains. This note draws the offline signed feature hash of seven invented sentences. It is a reproducibility stand-in. It is not a semantic embedding, and it is not evidence about meaning. Personal records are not in the repository, the nightly artifact, or this page.

1Selection

Cosine similarity, with a zero vector defined as similarity 0, is

cos(u, v) = (u · v) / (|u| |v|). (1)

Semantic bridge keeps a pair only when the fragments sit in different greedy-leader clusters (link 0.55) and the cosine lies in [0.05, 0.35]. The score is the novelty of the normalised midpoint against every other fragment,

m = normalize(normalize(u) + normalize(v)),S = 1 - max cos(m, vk). (2)

Analogical transfer keeps pairs from different domains whose cosine lies in [0.15, 0.55]. Inside that band the score is the cosine. Dialectic synthesis requires a listed lexical opposition and a cosine in [0.20, 0.75]; the score is tension times closeness to 0.45. The opposition list is a cue list, not an entailment check.

3The accept rule

The model fills four scores in [0, 1]. The composite and the accept bit are computed here, not taken from the model:

C = 0.30N + 0.30L+ 0.20F + 0.20U. (3)
accept if C >= 0.60and min(N, L, F, U) >= 0.30. (4)

A hypothesis is dropped before the critic when its nearest neighbour is above 0.88 or below 0.05. The template model used by the public cycle scores every axis at 0.50, so C = 0.500 and the report is rejected. Moving the rules below recomputes (3) and (4) and holds the animation.

4A private store

One command installs the program under the home directory and registers a local stdio server. Any chat client that can launch that process can call it. The command does not read a transcript and does not upload a database. No API key is required. The registered embedder is the offline hash and the registered model is the template.

curl -fsSL https://raw.githubusercontent.com/bernhardbrugger/rem-recombinator/main/install.sh | bash

Remark. Fragment text leaves the machine only if REM_EMBEDDER or REM_LLM is later pointed at an API and keys are added in the local environment. Those keys are not part of this page.

A corpus already on the machine is imported locally. A directory of notes uses the folder name as the domain. The command demo reruns this fictional sample in a temporary database.

rem-recombinator import ./fragments.json --embedder hashing
rem-recombinator import ./notes/ --embedder hashing
rem-recombinator demo

fragments.json has the shape {"fragments": [{"text": "...", "domain": "physics"}]}. The source of the procedure is github.com/bernhardbrugger/rem-recombinator.

Thresholds are the repository defaults. The plane is produced by scripts/build_demo_geometry.py and checked against that function. Latin Modern is used under the GUST Font License; the text is in fonts/GUST-FONT-LICENSE.txt.
