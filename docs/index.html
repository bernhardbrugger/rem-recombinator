REM Recombinator a computational note

REM Recombinator

Pairs chosen by geometry, and a critic that keeps almost nothing

Public note. The corpus is seven fictional sentences.

Abstract

Stored fragments are paired by a rule you can recompute. A model may propose one hypothesis from a pair. The hypothesis is discarded when its nearest neighbour falls outside a fixed window, and what remains is kept only if a four-axis score clears two thresholds that the model does not set. The name is a sketch of REM sleep, in which weakly linked traces are reactivated together and most collisions are noise. It is not a claim about brains. The figure on this page is the offline signed feature hash of an invented corpus, projected onto two principal components. It is a reproducibility stand-in, not a semantic embedding. Personal records are not in the repository, the nightly artifact, or this note.

Keywords. recombination, cosine geometry, novelty, private store.

1Selection

(1)

Three rules then keep a pair. Each one is a predicate on the stored vectors and the domain tags, followed by a score. None of them asks a model which pair is interesting.

Semantic bridge.
Greedy leader clustering at link 0.55. The pair must sit in different clusters, and the cosine must lie in [0.05, 0.35]. The score is the novelty of the normalised midpoint against every other fragment.
Analogical transfer.
The domains must differ, and neither may be unspecified. Inside [0.15, 0.55] the score is the cosine itself: a shared direction across tags.
Dialectic synthesis.
A documented list of lexical oppositions, matched on word boundaries, and a cosine in [0.20, 0.75]. The score is tension times closeness to 0.45. The list is a cue, not an entailment check.
(2)
Algorithm 1 One cycle
  1. Enumerate pairs in id order and keep those the chosen rule accepts. Above a size cap, sample with a seed.
  2. Ask for one hypothesis from the highest-scoring pair. The model does not choose the pair.
  3. Drop the hypothesis when its nearest neighbour is above 0.88 or below 0.05.
  4. Score four axes in [0, 1]. Accept only when (3) and (4) both hold. Write the parents, the hyperparameters, and the verdict.

4A private store

One command installs the program under the home directory and registers a local stdio server. Any chat client that can launch that process can call it. The command does not read a transcript and does not upload a database. No API key is required. The registered embedder is the offline hash, and the registered model is the template.

curl -fsSL https://raw.githubusercontent.com/bernhardbrugger/rem-recombinator/main/install.sh | bash

Remark. Fragment text leaves the machine only if REM_EMBEDDER or REM_LLM is later pointed at an API and keys are added in the local environment. Those keys are not part of this note.

A corpus already on the machine is imported locally. A directory of notes uses the folder name as the domain. The command demo reruns this fictional sample in a temporary database and does not open your store.

rem-recombinator import ./fragments.json --embedder hashing
rem-recombinator import ./notes/ --embedder hashing
rem-recombinator demo

fragments.json has the shape {"fragments": [{"text": "...", "domain": "physics"}]}. The source and the manual are at github.com/bernhardbrugger/rem-recombinator.

Thresholds are the repository defaults. The plane is produced by scripts/build_demo_geometry.py and checked against that function. Displayed mathematics is set with KaTeX, under the MIT license in vendor/katex/LICENSE. Latin Modern is used under the GUST Font License, in fonts/GUST-FONT-LICENSE.txt.
